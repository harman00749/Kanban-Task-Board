# Kanban Task Board

Kanban Task Board is a Trello-style task management application built with React and Vite. It helps users organize tasks across three workflow columns: To Do, In Progress, and Done.

# Features

- Add new tasks to the To Do column.
- Assign task priority: High, Medium, or Low.
- Show priority using colored card borders.
- Move tasks between columns with Previous and Next buttons.
- Drag and drop tasks between columns using dnd-kit.
- Edit task titles inline by clicking the task.
- Delete tasks from any column.
- Search tasks in real time.
- Save board data in browser localStorage.
- Keep tasks available after page refresh.

# Tech Stack

- React
- Vite
- JavaScript
- CSS
- dnd-kit
- localStorage

# How To Run

```bash
npm install
npm run dev
```
If PowerShell blocks npm, use:
```
npm.cmd install
npm.cmd run dev
```
Then open the local URL shown in the terminal, usually:
```
http://localhost:5173/
```
```bash
npm run build
```
